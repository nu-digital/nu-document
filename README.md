# 日本大学デジタル/メタバース創作プロジェクト 団体ドキュメント

日本大学デジタル/メタバース創作プロジェクトの公式ドキュメントリポジトリです。

本プロジェクトのドキュメントは、ViteとVue 3をベースにした静的サイトジェネレーター（SSG）である **[VitePress](https://vitepress.dev/)** を使用して構築されています。Markdownファイルを静的HTMLに変換する仕組みのため、非エンジニアのメンバーでも技術的な詳細に悩むことなく、コンテンツ作成に集中できます。

---

## 環境構築とセットアップ

編集を始める前に、事前にドキュメント内の「基本」を参考に環境構築を行ってください。

### 1. リポジトリのクローン

任意の作業ディレクトリで以下のコマンドを実行し、リポジトリをクローンします。

```bash
git clone [https://github.com/nu-digital/nu-document](https://github.com/nu-digital/nu-document)
```

### 2. ディレクトリの移動

```bash
cd nu-document
```

### 3. 依存パッケージのインストール

```bash
npm install
```

## ドキュメントの作成・編集方法

基本的には、`src/` ディレクトリ以下に Markdownファイル（`.md`）と使用する画像を配置するだけでドキュメントとして利用できます。

### サイドバーへの追加

新しく作成したページをサイトのサイドバーメニューに表示させるには、以下の設定ファイルに追記を行ってください。

- **設定ファイルパス:** `.vitepress/config.mts`

## ドキュメント構成

ドキュメントは、主に以下の5つのカテゴリに分かれています。用途に合わせて適切なカテゴリにドキュメントを追加してください。

| カテゴリ           | 概要                                               | 具体例・対象技術                       |
| :----------------- | :------------------------------------------------- | :------------------------------------- |
| **基本**           | 個人および共同開発に必要な基盤ツールの解説         | 必須ツールの導入手順、Gitの使い方 など |
| **システム系**     | 開発環境、プログラミング、フレームワークの技術情報 | Unity, VCC, C#, Udon, React, Go など   |
| **デザイン系**     | 3Dモデリングやデザインツールの情報                 | Blender, Canva, Adobeツール群 など     |
| **サウンド系**     | 楽曲制作や効果音などのサウンド関連情報             | ※現在未定                              |
| **プロジェクト系** | 企画立案や共同制作でのルール、規約関連             | 企画書、チーム制作の運用ルール など    |
