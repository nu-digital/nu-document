# GitHub

## GitHub とは？

- Git のリモートリポジトリ（共有サーバー）を提供する Web サービス
- オンライン上でコードを共有・公開・管理できる
- Git のデータをクラウドで扱えるようにしたもの

メタ創でもホームページの公開や、プログラムの共有に使われています。
今後のゲーム制作などで使うので、慣れておいてください。

::: tip
GitHub は「Git そのもの」ではなく、
Git で管理しているリポジトリを**インターネット上で共有する場所**です。
ローカル（自分の PC）での操作は Git、公開・共有は GitHub、という役割分担になります。
:::
