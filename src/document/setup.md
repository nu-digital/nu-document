# 環境構築

::: info
この手順は初回のみ必要です。
また基本をすべて終えた前提で進めていきます。
:::

## 1. Node.js のインストール

まず、Node.js をインストールしてください。  
（未インストールの場合は公式サイトからインストール）

インストールできているか、以下のコマンドで確認します。

```bash
node -v
npm -v
```

それぞれバージョン番号が表示されれば OK です。

## 2. リポジトリのクローン

デスクトップでターミナル（またはコマンドプロンプト）を開き、以下を実行します。

```bash
git clone https://github.com/yurarara23/NewDocs
```

## 3. リポジトリに移動

```bash
cd NewDocs
```

## 4. 依存パッケージのインストール

```bash
npm install
```

※ 初回は少し時間がかかります。

## 5. 開発サーバーの起動

```bash
npm run docs:dev
```

## 6. 動作確認

ブラウザで以下の URL にアクセスし、ページが表示されることを確認してください。

```
http://localhost:5173
```
